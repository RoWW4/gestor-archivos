# Usar «Archivos» como gestor principal (Nothing Phone 3a Pro · Android 15)

Android **no tiene** un ajuste de «gestor de archivos predeterminado» (como sí lo tiene para el navegador o los SMS). Lo que sí se puede hacer:

1. **Tenerla a mano.** Mantén pulsado el icono de «Archivos» y ponlo en la pantalla de inicio o en la barra de abajo, en lugar de «Files» de Google.
2. **Adjuntar o subir archivos** (WhatsApp → Documento, Gmail → Adjuntar, el navegador → Subir archivo). Se abre el selector de Android: toca **☰** (arriba a la izquierda) y elige **Archivos**. Ahí buscas y filtras como siempre y tocas el archivo para enviarlo. Android no deja fijarla para siempre en este selector.
3. **Botones «Ver descargas»** de otras apps. La primera vez Android pregunta con qué app: elige **Archivos** y **Siempre**. Se abrirá con el filtro Descargas puesto.
4. **Abrir un archivo** (una foto, un PDF) lo hace la app de ese tipo (Fotos, lector de PDF…), no el gestor. Si alguna vez eliges «Siempre» con la app equivocada: Ajustes → Aplicaciones → esa app → Abrir de forma predeterminada → Borrar preferencias.

Opcional: si no quieres ver «Files» de Google, en Ajustes → Aplicaciones → Files puedes desactivarla. Algunos atajos del sistema (como «Liberar espacio» en Almacenamiento) dejarán de funcionar mientras esté desactivada.
